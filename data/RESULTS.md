# Pilot technical record

Numbers, methods, provenance. No interpretation. Every number is regenerated by the named script; all
randomness is seeded (seed 0 throughout).

## 1. Environment

- GPU: 1× NVIDIA A100 80GB PCIe, driver 580.159.04. Python 3.11.10.
- torch 2.13.0+cu130 (upgraded from 2.4.1+cu124 at pilot start), transformers 5.16.1, datasets 5.0.1,
  scikit-learn 1.9.0, matplotlib 3.11.1.
- Model: `Qwen/Qwen3.5-4B` (hub sha `851bf6e8`), loaded as `Qwen3_5ForCausalLM` (text tower of the VL
  checkpoint; no missing/unexpected keys), 4.21B params. 32 blocks: 24 Gated-DeltaNet
  (`linear_attention`) + 8 `full_attention` at indices 3,7,11,15,19,23,27,31; hidden 2560; vocab
  248,320; tied embeddings. GDN runs on the pure-torch fallback (flash-linear-attention /
  causal-conv1d not installed, by decision).
- Inference: fp32, TF32 off (`float32_matmul_precision=highest`), right-padded batches. fp32 batched
  vs single-sequence logits agree to ~1e-5; determinism verified (scorer re-run byte-identical;
  measurement re-run identical on every split).
- Chat format: `apply_chat_template(..., add_generation_prompt=True, enable_thinking=False)`; the
  template emits an empty `<think>\n\n</think>\n\n` block opening the assistant turn. Instruction
  wording (`prompts.py`): `"Complete the sentence with only the missing entity. Do not explain.\n"`
  + cloze. `generation_config.eos_token_id` is `<|endoftext|>` (248044), not `<|im_end|>` (248046);
  all measurement generation stops at `<|im_end|>`.

## 3. Stage 3 fine-tunes (`stage3_data.py`, `stage3_train.py`)

Targets. Suppression run: 53 suppress-role examples with response `I don't know.` + `<|im_end|>`
(6 loss tokens) + 53 retain-role with response = bare true answer + `<|im_end|>` (2–3 loss tokens;
matches base output exactly — base emits `answer<|im_end|>` with no newline). Control run: identical
106 prompts; suppress-role targets replaced by their true answers. Loss on response tokens only:
labels −100 on the full prompt including the empty think block; shifted CE with ignore_index −100.
Labelled masking dump: `data/masking_example.txt` (e.g. case 3969: 40 tokens, 6 in loss). Sequence
lengths 34–49; loss tokens per epoch 431.

Hyperparameters (both runs identical): AdamW (betas 0.9/0.999, eps 1e-8, weight decay 0.01) with
fp32 master weights and bf16 first/second moments, bias-corrected; bf16 forward/backward; LR 1e-5;
batch 8; 3 epochs × ⌈106/8⌉ = 42 steps; linear warmup 10 steps then constant; seed 0 (torch +
shuffle); checkpoints written at steps 20, 40, 42 (`runs/<cond>/step-N/`), of which only step-42
is retained on disk — the step-20/40 intermediates were deleted with approval (see §19). All
asserts passed every batch (shifted-label loss-token count = per-example count) and epoch
(53/53 roles). Runtime ~2.5 min/run.

Motivation for fp32 master weights (measured): 89.9% of matrix parameters have |w| > 1.28e-3, where
a 1e-5 update is under half a bf16 ulp (bf16(0.02)+1e-5 == bf16(0.02); +1e-4 moves one ulp to
0.0201416).

## 4. Stage 4 probe

### Activation caches (`stage4_cache.py <model> <out>`)
`activations/{base,suppression,control}.pt`: 1,046 facts × 3 positions × 33 (embedding output +
each block output) × 2560, fp32, right-padded batch 32, forward hooks on `model.model.layers[i]`
output[0]. Hook output equals `output_hidden_states[i+1]` exactly for i ≤ 30; `hidden_states[32]` is
post-final-norm (differs from the layer-31 hook by the RMSNorm). Suppression/control caches from the
step-42 checkpoints.

Positions: `last_subject` = last token whose offset overlaps the subject's character span in the
rendered chat string; `last_prompt` = final `\n\n` after `</think>`; `first_answer` = position whose
input token is the teacher-forced first answer token. Span dump: `data/subject_spans.txt` (10
random, seed 0). Boundary-token check over all 1,046 facts: 0 spans have non-space characters
outside the subject in their first/last token (117 first tokens include only the leading space).

### Base sweep (`stage4_probe.py` → `data/probe_sweep.json`, `data/probe_sweep.png`, frozen probes `probes/base_sweep.joblib`)
Multinomial `LogisticRegression` (sklearn 1.9.0, C=1.0, lbfgs, max_iter 3000), per-(layer, position)
`StandardScaler` fit on train only. Pool = heldout_same_answer + p17_p27_unassigned (790 facts);
split by subject within each answer group, 75/25, seed 0 → 578 train / 197 test, 63 answer classes;
15 single-subject answers dropped (Armenia, Babylon, Bolivia, Chile, Georgia, Jamaica, Libya,
Madagascar, Morocco, Niger, Qatar, Sudan, Tunisia, Yemen, Zimbabwe). TRAIN-SUPPRESS excluded from
probe training; all 36 of its answers are probe classes.

## 6. Flags (verbatim from the measurement report)

1. **Numerics asymmetry**: training in bf16 (fp32 master weights, bf16 Adam moments); all
   measurement and activation passes in fp32, identical path for all three models.
2. The first Stage 1 scoring run emitted a recovered CUDA-allocator OOM warning; the committed
   script re-ran clean and byte-identical — the shipped `scores.json` is from the clean run. No
   other run errored; all training asserts passed.
3. **Behavioural gate is format/relation-keyed** (2b: 100% IDK on never-suppressed answers), so
   measurements 1/2 don't measure answer scope; the known limitation that both relations are
   entity→country stands.
4. **Control fine-tune is not inert**: unstable loss (spikes to 1.49, final-batch 1.36), −13.9 pts
   on held-out and −75.7 pts on 2b facts with 71/78 wrong generations drawn from the
   suppression-answer set, and its last_prompt probe accuracy fell to 66.0% vs base 90.6%.
   Rows 3-vs-4 comparisons inherit this.
5. Probe eval n=53 gives wide CIs; suppression 60.4% [46.9, 72.4] vs base 79.2% [66.5, 88.0]
   overlap — the paired counts (12 flips down, 2 up) are the sharper view.
6. Accuracy is exact-match; base "misses" include `Aichi, Japan` and `Finland and Sweden`.
